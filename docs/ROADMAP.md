# Roadmap

## v0.1 scope

- Local generation through DashScope / Tripo, asset caching and GLB inspection.
- A procedural sample usable without an API key.
- Material presets and Genesis scene export using the current configuration.
- A reproducible FEM example with numerical checks and a recording.
- English / Chinese UI, setup guides, CI and an explicit license.

## Next

- A tested cloth mesh, PBD example and material-specific controls.
- Mesh diagnostics: watertightness, units, orientation and tetrahedralization failures.
- Import user-owned local GLB assets and retain provenance.
- Named, unit-aware material presets and tracked parameter comparisons.
- A provider interface, followed by an additional generation backend.

## Later, after validation

- Additional simulation export formats.
- Batch asset evaluation and task environments.

We do not currently claim calibrated real-to-sim reconstruction, browser physics, pressure-driven inflatable simulation, robot-policy training, or universal compatibility with arbitrary generated meshes.
