# Real2Sim Studio v0.1.0 Alpha

A local-first asset-to-simulation workbench with a reproducible, original example.

## Included

- Offline mode with a self-authored MIT procedural GLB, isolated task storage and disabled paid generation calls.
- Geometry preview, rotation, English/Chinese UI and material presets.
- Genesis archive export using the current sliders, including gravity. Downloads work from the default hidden `.data` directory.
- A Genesis 1.4.5 FEM runtime, implicit CPU solver, camera recording, trajectory and numerical metrics.
- Optional DashScope / Tripo text, image and multi-image integration. Paid generation was not called during this release verification.
- MIT license, third-party notices, contribution guide, security notes, CI and bilingual documentation.

## Verification on 2026-10-28

Reference environment: macOS 15.7.7 ARM64, Python 3.11.15, Genesis World 1.4.5, PyTorch 2.14.1, Node 24.14.0.

- 16 TypeScript tests and 2 numerical-metric unit tests passed.
- Lint and production build passed. The Three.js-containing JS bundle remains large (about 1.2 MB before gzip).
- Browser smoke tests verified a real GLB archive, gravity 3.7, hidden-directory download, nonblank canvas pixels, rotation, and mobile layout without horizontal overflow.
- The original sample ran for 800 steps of 0.002 s on CPU. All sampled positions were finite; the body fell onto the ground and changed shape. See [metrics](../verification/genesis-cpu.json).
- Shape deformation is measured after removing translation and rigid rotation with Kabsch alignment. It is not an accuracy benchmark against a real object.
- The native recording contains 1.6 seconds of simulated time. The introduction clearly labels slowed replay. Kernel compilation time is not presented as real-time performance.
- Node `npm audit`: 0 reported vulnerabilities at verification time. The optional Python audit is not clean; see below.

## Important limitations

This is an **Alpha**, not a calibrated digital-twin or robot-training system. Material values are illustrative presets; arbitrary meshes may fail tetrahedralization. Cloth export is experimental and is not validated by the solid example. Inflatable/soft-robot presets do not model pressure or actuators. A prompt-generated flexible variant is a new generation, not physical modification of its source mesh.

The optional Python stack has known Pillow advisories constrained by MoviePy's Pillow <12 requirement. Do not process untrusted assets. Use the bundled example in an isolated environment without credentials or private data. See [SECURITY.md](../../SECURITY.md) for the unresolved dependency issue; no advisory was silently ignored.

The browser is only a geometry preview. It does not run Genesis physics. The workbench is a local single-user application; do not expose its development servers publicly.

## Reproduce

```bash
npm ci
npm run demo
# In a separate terminal, after configuring the Python environment:
npm run example:export
python .data/genesis-packages/example-soft-puck/genesis_scene.py --steps 800 --record
python scripts/verify-physics.py
```

See the [example guide](../../examples/README.md). The media uses the original procedural sample, actual UI captures and native Genesis recording, with synthetic narration and no cloned voice or third-party music.
